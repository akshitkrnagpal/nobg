---
title: Deploy the API Worker
description: Configure and deploy nobg, set its secret, and check your endpoint.
---

Run the commands below from the repository root. They deploy the API Worker in `apps/api`.

## 1. Prepare your account and checkout

You need Node.js 22.14 or newer, pnpm 11, Git, and access to the repository, which is currently private. Use the pnpm version pinned in the root `package.json`.

```sh
git clone https://github.com/akshitkrnagpal/nobg.git
cd nobg
pnpm install --frozen-lockfile
```

Your Cloudflare account needs Workers access and the Images access required for background removal. Review [requirements and costs](/docs/costs/). Installing dependencies and running local checks do not call the paid Images service.

Log in and confirm the account you will deploy into:

```sh
pnpm --filter @nobg/api exec wrangler login
pnpm --filter @nobg/api exec wrangler whoami
```

## 2. Configure the Worker

Open `apps/api/wrangler.jsonc` and review these settings:

| Setting | What to do |
| --- | --- |
| `name` | Keep `nobg-api` or choose a name that does not conflict with another Worker in your account. |
| `images.binding` | Keep `IMAGES`, the binding name used by the handler. |
| `ratelimits[0].namespace_id` | Choose a numeric namespace ID unused by your other rate limiters. The example is `1001`. |
| `vars.MAX_UPLOAD_BYTES` | Keep `10485760` for a 10 MiB file limit, or adjust it within the supported range. |

Keep `main`, `compatibility_flags`, and both binding names as supplied. If Wrangler can access multiple accounts, add your intended `account_id` to this file. See [Worker configuration](/docs/configuration/) for the full settings.

## 3. Check and deploy

```sh
pnpm --filter @nobg/api typecheck
pnpm --filter @nobg/api test
pnpm --filter @nobg/api build
pnpm --filter @nobg/api run deploy
```

The `build` command bundles the API with Wrangler's `--dry-run` option. The `deploy` command publishes it. Tests use mocked Images responses.

Wrangler prints a URL such as `https://nobg-api.YOUR-SUBDOMAIN.workers.dev`. Save that URL. The upload endpoint returns `503 not_configured` until you set the API key.

Use the filtered deploy command above. The repository's root `pnpm run deploy` command publishes the documentation website.

## 4. Set the API key

Generate a random key of at least 32 characters in your password manager. Keep a copy there and paste it into Wrangler's interactive prompt:

```sh
pnpm --filter @nobg/api exec wrangler secret put API_KEY
```

`API_KEY` belongs to this Worker. Do not put it in `wrangler.jsonc`, Git, or frontend JavaScript. A local `.dev.vars` file does not configure a deployed Worker's secrets.

## 5. Check the endpoint without processing an image

Set `NOBG_URL` to the URL Wrangler printed, with no trailing slash:

```sh
export NOBG_URL="https://nobg-api.YOUR-SUBDOMAIN.workers.dev"
curl --fail-with-body "$NOBG_URL/api/health"
```

Expect:

```json
{ "status": "ok", "service": "nobg", "version": "0.1.0" }
```

This confirms the Worker responds. It does not verify the key, Images binding, or paid-service access.

Load the same key into your shell as `NOBG_API_KEY` using your secret manager. To check authentication without uploading an image:

```sh
curl --include --request POST \
  "$NOBG_URL/api/v1/remove-background" \
  -H "Authorization: Bearer $NOBG_API_KEY"
```

Expect `400 invalid_request` because the body is missing. That response means the request passed the key check. `401` means the key did not match; `503` means the Worker is not configured. This request does not call Images, but it counts toward the rate limit.

## 6. Process an image when you are ready

This step calls Cloudflare Images and may incur charges. You can stop after the checks above until your account has the required access.

With `photo.jpg` in your working directory:

```sh
curl --fail-with-body \
  "$NOBG_URL/api/v1/remove-background" \
  -H "Authorization: Bearer $NOBG_API_KEY" \
  -F "image=@photo.jpg" \
  --output nobg.png
```

A successful response contains PNG bytes. On failure, the saved body is JSON describing the error. Inspect it before treating the file as an image. Add `-F "format=webp"` and use a `.webp` output filename for WebP.
