## API settings

Configuration lives in `apps/api/wrangler.jsonc`.

| Setting | Default | Purpose |
| --- | --- | --- |
| `name` | `nobg-api` | Cloudflare Worker name |
| `IMAGES` | Images binding | Inspects and transforms image bytes |
| `MAX_UPLOAD_BYTES` | `10485760` | File size cap, 10 MiB |
| `RATE_LIMITER` | 30 requests / 60 seconds | Limits authenticated upload attempts |
| Rate limiter namespace | `1001` | Set this to an unused namespace in your account |
| Observability sample rate | `0.1` | Samples Worker observability events |

`MAX_UPLOAD_BYTES` must be a positive integer no larger than `20971520`, Cloudflare's documented 20 MiB binding input limit. The request body allowance adds 64 KiB for multipart headers; exceeding either cap is rejected.

The application also limits decoded images to 25 megapixels. Change the shared constant in `packages/contracts` if you deliberately want a different policy.

## API key

`API_KEY` is a secret, not a Wrangler `vars` value. Use a random string with at least 32 characters. Missing keys, short keys, and the example placeholder all fail closed with `503 not_configured`.

For local development, put it in `apps/api/.dev.vars`. In Cloudflare, use:

```sh
pnpm --filter @nobg/api exec wrangler secret put API_KEY
```

One key authorizes the service. There are no per-user keys, accounts, or usage dashboards.

## Rate limits

The limit applies to the service's authenticated requests within each Cloudflare location. It is approximate and is not a global billing cap. All clients of this single-key deployment share the limit. Use Cloudflare's account controls and monitor usage if you need cost oversight.

## Website settings

`apps/web/wrangler.jsonc` deploys static assets as `nobg-web`. It contains no image binding, API secret, or API code. The root `pnpm run deploy` command only publishes this website.

After changing binding configuration, regenerate API types:

```sh
pnpm --filter @nobg/api types
```
